- Chatbot API Gateway IA + Express.js + historial en MongoDB + React
--------------------------------------------------------------------------------------------------------
    - Chatbot en React con botón de limpieza, auto-scroll y visor del proveedor de IA activo en cada momento.
    - Memoria Persistente (MongoDB): El historial de cada chat se guarda vinculado a un `userId`, recuperando su conversación.
