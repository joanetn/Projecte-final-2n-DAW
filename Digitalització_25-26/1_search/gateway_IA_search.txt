- Agent IA RAG Recommendations + API Gateway IA  + Express.js + MongoDB
--------------------------------------------------------------------------------------------------------
    - Búsqueda: El servidor filtra los productos usando lógica de similitud.
    - Generación: Envía el contexto a uno de los 6 proveedores (Groq, Gemini, etc.).
    - Persistencia: Guarda en la colección recommendations el resumen de lo ocurrido.

API Gateway IA
--------------------------------------------------------------------------------------------------------
    1. **Arquitectura Multi-Proveedor:** Un sistema que unifica gigantes de la IA.
    2. **Sistema de Round-Robin:** El servidor rota automáticamente entre los proveedores.
    3. **Manejo de Errores con Fallback (Reintento):** Si un proveedor falla, el sistema **salta instantáneamente al siguiente**.
    4. **Streaming Nativo:** Se envía palabra por palabra al cliente, lo que mejora la experiencia de usuario.
    5. Health Check - blacklist
    6. attempts
